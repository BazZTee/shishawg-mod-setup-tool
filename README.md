# ShishaWG Mod Setup Tool

Ein spezialisiertes Moderator-Tool für den **ShishaWG** Twitch-Kanal zum schnellen Erstellen, Importieren und Live-Senden des Stream-Setups in den Twitch-Chat.

## 🌟 Hauptfunktionen

- **Twitch-Integration**: Ein-Klick-Senden von `!editsetup` Befehlen direkt in den Chat (`#marved`).
- **Live Cloud Auto-Sync (GitHub Gists)**: Alle Pfeifen, Köpfe, HMDs und Tabaksorten synchronisieren sich automatisch live zwischen allen Moderatoren.
- **Flexibles Personen-Grid**: Unterstützt 1 bis 10 Personen mit dynamischen Tabaksortenslots.
- **Setup-Import**: Liest Live-Setups per Chat-Befehl oder manuell per Text/Zwischenablage ein.
- **Zusatz-Commands & Promos**: Ermöglicht das gezielte Anfügen von Commands (`!kohle`, `!xk`) hinter Pfeife, Kopf, HMD oder Kohle.
- **Auto-Updater**: Prüft automatisch auf neue Versionen und installiert sie auf Wunsch per Klick.
